Lex now has the full supervisor surface:

- Slice A leak fix: pty.onExit ends the brainstorm row so killing a
  Lex PTY no longer leaves status='active' rows behind.
- Slice B source-aware retrieval: /lex/recall ranks with a 5-tier
  source-class multiplier (canonical 1.0 / pending 0.85 / brainstorm
  0.7 / raw 0.6 / reference 0.5), bundles brainstorm chunks under
  their session, exposes provenance + raw_score.
- Slice C artifact extraction: every assistant turn on a brainstorm
  PTY is scanned for fenced JSON blocks (research-note, wiki-draft,
  project-intent, notes-summary). Persisted to disk under
  <DATA_ROOT>/lex/artifacts/<kind>/<id>.json and linked into the
  brainstorm row. notes-summary fans out into the reminders system.
- Slice D system prompt rewritten as four mode contracts (brainstorm,
  retrieval, research, orchestration) with one invariant voice. RTX
  4080 hardcode and absolute paths are gone; Lex queries /health and
  /lex/snapshot for live state. Adds artifact contracts and a
  self-check rubric. Iterated twice today after first user feedback:
  brainstorm shape now allows brief lists for enumerative questions
  but bans paths, ids, and bold-bombing; explicit synthesis directive
  added so Lex stops reciting the snapshot back as a directory tree.
- Slice E supervisor primitives: POST /lex/steer/:sessionOrPty wraps
  ptyInject; POST /lex/capture creates reminders + links into the
  brainstorm row; GET /lex/snapshot returns live env+state envelope;
  /lex/recall now sets conflict_check_required when canonical wiki
  and brainstorm both hit, with a conflict_overlap envelope.

Voice loop UX fixes (post-first-real-use):
- Mute mid-utterance now auto-finalizes. A parallel ScriptProcessor
  capture rig runs alongside silero VAD; muting flushes the buffer
  and sends utterance-end so Lex still replies instead of dropping
  the audio.
- Notes-mode stop emits a summary. Pressing stop in notes mode sends
  {t:'finalize-notes'} which ptyInjects a synthetic prompt asking
  Lex to emit a notes-summary artifact. Slice C parser handles
  persistence + reminder fan-out. Client tears down ~750ms after
  the assistant-text turn lands, with a 30s timeout fallback.
- AudioContext resume on every tts-start so Chrome and Safari do
  not silently suspend playback after a tab switch or mute toggle.
- Voice-mode marker: every transcribed inject is prefixed with
  [voice mode] (or [voice mode: notes ...]) so Lex's prompt knows
  this turn is going through TTS and enforces voice rules at full
  strength without needing per-session prompt mutation.

Whisper env defence:
- User-scope env var DEVNEURAL_WHISPER_BIN was pinned to
  C:\dev\whisper.cpp\Release\whisper-cli.exe (CPU-build CLI, wrong
  binary type). whisper-cli does not accept --host/--port, exits
  clean with code 0, and the daemon timed out at "whisper-server
  failed to come up". Corrected the persistent env to the cuBLAS
  server path. Added a defensive correctIfWhisperCli() in
  07-daemon/src/voice/whisper.ts so future drift self-heals with a
  one-shot warning in the daemon log instead of silent STT failure.
